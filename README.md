This project aims to construct and analyze a citation network of early logic-related articles using data from the journal Mind, beginning with Volume 1 (1876). 
The goal is to explore how works in logic reference one another and to represent these relationships as a directed graph.

The JSON file contains articles, along with their metadata, from the journal Mind with the words "logic" or "logical" in the title.
